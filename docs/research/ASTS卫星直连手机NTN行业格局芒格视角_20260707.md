# AST SpaceMobile（ASTS）行业研究：卫星直连手机 / NTN 格局与竞争态势

> 角色：industry-researcher  
> 视角：芒格式反向思考，先找“会怎么输”  
> 数据截止：2026-07-07  
> AI 可研究性评级：B/C 边界。公开资料中等，技术和监管事实较多，但商业化仍早，预测跨度大；本文严格区分“已验证事实 / 公司目标 / 第三方预测”。

## 1. 一句话结论

D2D/NTN 方向真实但商业化尚早，ASTS 的普通手机宽带路线差异化强、赔率高，但仍受 SpaceX、终端平台、运营商议价、CAPEX 和监管节奏共同约束。**投资建议：观察名单 / 高风险期权，行业与 ASTS 评分均为 ★★★☆☆（3/5），不能按已验证复利资产定价。**

## 2. 核心结论

**行业评分：★★★☆☆（3/5）**

卫星直连手机（D2D）/ 非地面网络（NTN）是真需求，但不是一个已经验证的好生意。它解决的是地面网络永远难以经济覆盖的“最后 5%-15% 地理面积 / 偶发连接 / 应急连接”问题，而不是替代蜂窝网络。芒格式结论是：**方向大概率对，商业化速度、容量经济性和价值分配仍高度不确定。**

对 AST SpaceMobile（ASTS）而言，最有吸引力的地方是它选择了“标准手机 + 运营商频谱 + 宽带蜂窝”的高难度路线；如果成功，差异化明显。最危险的地方也正是这里：资本开支、卫星展开、频谱协调、运营商商业激励和终端体验必须同时成立。这个行业目前更像“牌桌刚开始下注”，而不是“赢家已经清晰收租”。

## 3. 事实、目标、预测三分法

| 类型 | 代表内容 | 可信度处理 |
|---|---|---|
| 已验证事实 | 3GPP 已把 NTN 纳入 Release 17；FCC 已建立 Supplemental Coverage from Space（SCS）框架；Apple / Globalstar 已提供 iPhone 卫星 SOS；Starlink Direct to Cell 已与运营商测试并推进短信服务；ASTS 已发射 BlueWalker 3 和首批 BlueBird | 可作为行业存在性的证据 |
| 公司目标 | ASTS 计划建设 SpaceMobile 星座并与 MNO 分成；SpaceX 计划从短信扩展到语音、数据和 IoT；Lynk 计划通过小卫星与 MNO 合作覆盖普通手机 | 只能作为管理层路线图，不能当作收入事实 |
| 第三方预测 | D2D/NTN 未来十年收入、连接数、终端渗透率预测 | 只能用于市场天花板感知，不能用于精确估值 |

## 4. D2D / NTN 市场规模、增长与渗透率

### 4.1 需求本质：覆盖缺口，而非蜂窝替代

全球移动网络的问题不是城市容量，而是偏远地区、海上、空中、灾害中断和跨境漫游的经济性。地面基站要持续供电、回传、维护和拿站址，在低人口密度区域 ROI 很差。卫星 D2D 的价值来自“把低频、低时长、低 ARPU 但高刚需的连接需求打包卖给运营商或终端平台”。

```text
地面网络边际成本上升
    -> 偏远/灾害/海空场景覆盖缺口长期存在
        -> 卫星 D2D 提供补盲与应急连接
            -> 运营商、手机厂商、卫星运营商争夺价值分配
```

### 4.2 市场规模口径

| 指标 | 现状 / 判断 | 来源属性 |
|---|---:|---|
| 全球移动连接基数 | 以数十亿手机用户和数十亿蜂窝连接为基础，D2D 的 TAM 看起来巨大 | 已验证宏观事实 |
| 真正可付费 D2D 场景 | 应急短信、低速消息、偏远地区补盲、IoT、政府/企业韧性通信、海空陆移动场景 | 业务判断 |
| 2030 年前渗透率 | 很可能先从高端手机和特定运营商套餐渗透，普及速度取决于终端芯片、频谱监管和服务体验 | 行业推断 |
| 收入规模 | 第三方预测差异很大，从数十亿美元到更高区间；早期收入更可能来自批发、最低承诺、设备/服务包，而非纯零售 ARPU | 预测，高不确定 |

**芒格式提醒：TAM 大不等于利润池大。** 如果 D2D 最终只是手机套餐里的“免费应急功能”，价值可能被 Apple、运营商或 SpaceX 吸走，纯卫星网络公司的经济性会被压缩。

### 4.3 增长节奏判断

| 阶段 | 时间 | 主流服务 | 关键瓶颈 |
|---|---|---|---|
| 1. 应急消息 | 2022-2026 | SOS、短信、低速消息 | 终端兼容、监管授权、可用性 |
| 2. 运营商补盲 | 2025-2028 | 普通手机短信、窄带数据、部分语音 | 星座规模、容量、MNO 频谱协调 |
| 3. 宽带化尝试 | 2027 以后 | 更高速数据、企业/政府/农村替代覆盖 | CAPEX、卫星寿命、单位比特成本、干扰控制 |

## 5. 竞争格局

### 5.1 竞争地图

```text
终端入口：Apple / Samsung / Android OEM / Qualcomm / MediaTek
    |
地面运营商：T-Mobile / AT&T / Verizon / Vodafone / Rakuten / Bell / Telefonica 等
    |
卫星 D2D 网络：
    - SpaceX Starlink Direct to Cell：低轨巨型星座 + 发射一体化
    - AST SpaceMobile：大相控阵卫星 + 普通手机宽带蜂窝路线
    - Lynk Global：小卫星 + 普通手机消息/低速服务路线
    - Globalstar / Apple：专用频段 + iPhone SOS/消息生态
    - Iridium：L-band 全球窄带网络，Qualcomm 消费手机合作终止后转向标准化 IoT/NTN
    - 传统卫星运营商：Viasat/Inmarsat、Eutelsat OneWeb、SES、EchoStar 等
```

### 5.2 主要玩家对比

| 玩家 | 路线 | 优势 | 短板 | 对 ASTS 的威胁 |
|---|---|---|---|---|
| SpaceX Starlink Direct to Cell | Starlink V2 / V2 mini 搭载直连蜂窝载荷，使用运营商频谱，先短信后数据 | 发射成本、星座规模、迭代速度、品牌、T-Mobile 等合作 | 早期容量有限；监管和干扰审查；移动运营商担心被平台化 | 极高。最强执行者，可能把 D2D 做成低价补盲功能 |
| Lynk Global | 小卫星直连普通手机，先消息和低速服务 | 技术路径轻、先发测试多、对 MNO 友好 | 资本和星座规模弱于 SpaceX / ASTS；宽带能力有限 | 中。更像低速补盲竞争者 |
| Globalstar / Apple | Globalstar 卫星网络 + Apple 终端生态，iPhone Emergency SOS | Apple 控制终端和用户体验；Globalstar 有频谱和网络 | 主要是 Apple 生态和应急/消息场景，非开放 MNO 宽带网络 | 中。占据高端手机应急心智，压缩 D2D 付费意愿 |
| Iridium / Qualcomm | Iridium L-band 星座；Snapdragon Satellite 消费手机合作已终止，转向 Project Stardust / 标准 NTN | 真正全球覆盖、L-band 稳定、企业/政府基础 | 带宽低；消费手机入口受挫；终端生态依赖芯片/OEM | 中低。窄带强，宽带威胁有限 |
| 传统卫星运营商 | GEO/MEO/LEO 宽带、IoT、回传、企业通信 | 频谱、客户、监管经验、现金流 | 多数不是“普通手机直连”原生架构 | 中。可能通过并购/合作进入 |
| 地面运营商自建/合作 | 与 SpaceX、ASTS、Lynk、Sateliot 等合作，或购买容量 | 持有客户、账单、频谱和监管关系 | 自建卫星不经济；技术依赖外部 | 高。运营商是入口，能决定谁拿利润 |

### 5.3 运营商合作格局

| 卫星方 | 典型合作方 | 商业含义 |
|---|---|---|
| ASTS | AT&T、Verizon、Vodafone、Rakuten、Bell、stc 等公开合作/投资/商业协议 | 证明 MNO 愿意给 ASTS 上牌桌，但大规模收入仍依赖星座部署 |
| SpaceX | T-Mobile、Optus、Rogers、KDDI、One NZ、Salt 等 | Starlink 用全球星座复制 MNO 合作，速度优势明显 |
| Lynk | 多国 MNO 与监管试点 | 更适合低速覆盖和小市场快速落地 |
| Globalstar | Apple | 终端平台直接定义需求，MNO 被弱化 |

## 6. ASTS 的竞争位置与差异

### 6.1 ASTS 的差异化

| 维度 | ASTS | 竞争含义 |
|---|---|---|
| 终端 | 目标是普通未改装手机 | 降低用户采用门槛 |
| 网络路线 | 大型 LEO 卫星相控阵，直接连接蜂窝频段 | 技术难度高，但若成功容量和体验可能优于窄带路线 |
| 商业模式 | 与 MNO 合作，用运营商频谱和客户关系，收入分成/批发 | 避免自己获客，但让渡入口和定价权 |
| 护城河 | 卫星设计、专利、MNO 合作、频谱协调经验、先发试验数据 | 护城河仍处建设期，不是已兑现垄断 |
| 风险 | 资金需求、发射节奏、卫星寿命、服务质量、监管审批、竞争降价 | 任何一环出问题都会延迟商业化 |

### 6.2 ASTS 的相对位置

ASTS 不是最有规模优势的玩家，SpaceX 才是；也不是最有终端入口的玩家，Apple 才是；也不是最稳的窄带卫星网络，Iridium 更成熟。ASTS 的投资逻辑是：**在普通手机宽带 D2D 这个更高价值环节，ASTS 可能拥有比 Lynk / Iridium 更大的服务上限，同时比 Apple / Globalstar 更开放给全球运营商。**

这是一条“高赔率但高执行风险”的路线。芒格会问：如果 SpaceX 把 D2D 当作 Starlink 附加功能低价打包，ASTS 的单位经济性还剩多少？如果运营商只愿意为应急覆盖付很低批发价，ASTS 的巨额星座 CAPEX 由谁承担？

## 7. 产业链价值分配

| 环节 | 代表参与者 | 价值来源 | 议价权判断 |
|---|---|---|---|
| 卫星制造与载荷 | ASTS 自研/供应链、SpaceX、传统卫星制造商 | 天线、功放、热控、软件定义载荷 | 技术难但资本密集，规模不足时议价权弱 |
| 发射 | SpaceX、Rocket Lab、Arianespace、印度/中国发射体系 | 低成本高频发射 | SpaceX 议价权最强，且是竞争者 |
| 频谱 | MNO 频谱、卫星频谱、监管授权 | 合法连接手机的稀缺资源 | MNO 和监管机构议价权高 |
| 网络运营 | ASTS、Starlink、Lynk、Globalstar、Iridium | 覆盖、容量、SLA、漫游/批发 | 早期取决于可用星座和服务质量 |
| 终端 | Apple、Samsung、Qualcomm、MediaTek、Android OEM | 用户入口、芯片/天线支持、OS 体验 | 极高。终端平台可把服务商品化 |
| 零售与账单 | MNO、Apple、企业/政府渠道 | 客户关系、套餐、客服、监管合规 | 极高。谁控制账单，谁拿走大部分消费者剩余 |

**最可能吃到超额利润的环节：终端平台、频谱/客户入口、低成本发射 + 星座运营一体化。**  
**最容易被压价的环节：纯卫星容量批发商，除非服务体验明显稀缺。**

## 8. 技术与监管趋势

### 8.1 技术趋势

| 趋势 | 影响 |
|---|---|
| 3GPP NTN 标准化 | 降低生态碎片化，帮助芯片、手机、运营商按统一路线适配 |
| 从专用终端转向普通手机 | 扩大 TAM，但链路预算、天线增益和功耗挑战更大 |
| 从窄带 SOS 转向消息、语音、低速数据 | 商业价值提高，但容量和干扰管理难度上升 |
| 大型相控阵卫星 | 有机会提升普通手机连接能力，但部署、姿控、热控和资本开支更难 |
| 星地融合核心网 | MNO 更容易把卫星作为漫游/补盲层集成进套餐 |

### 8.2 监管趋势

FCC 的 SCS 框架是行业里程碑：它承认卫星可在一定条件下使用地面移动频谱提供补充覆盖，但核心约束是**不得对地面网络和邻频用户造成有害干扰**。这意味着商业扩张不是单纯发卫星，还要逐国拿授权、协调频谱、证明干扰可控。

| 监管变量 | 对行业影响 |
|---|---|
| SCS / NTN 许可 | 决定能否商用 |
| 频谱协调 | 决定覆盖国家和运营商合作范围 |
| 天文、轨道碎片、发射许可 | 影响星座部署速度 |
| 紧急通信政策 | 可能推动 SOS 普及，也可能限制收费模式 |
| 国家安全和数据主权 | 跨境服务必须本地合规，全球统一网络会被切碎 |

## 9. 新进入者与替代方案风险

| 风险 | 概率 | 影响 | 芒格式判断 |
|---|---:|---:|---|
| SpaceX 低价横扫 D2D 补盲 | 高 | 高 | 最大竞争风险。它有发射、星座、资本和执行速度 |
| Apple / Android 把卫星服务做成终端内置功能 | 中高 | 高 | 卫星运营商可能沦为后台批发网络 |
| MNO 只把 D2D 当低价增值服务 | 高 | 高 | TAM 大但 ARPU 小，是最常见的投资陷阱 |
| 地面网络继续扩张、HAPS/无人机补盲 | 中 | 中 | 热点区域可能被地面或近地平台更经济地覆盖 |
| 监管和干扰限制降低容量 | 中高 | 高 | 频谱不是无限资产，跨国复制速度会低于技术演示 |
| 终端芯片路线变化 | 中 | 中 | 标准化有利行业，但也会削弱单家公司专有性 |
| 资本市场关闭，星座融资不足 | 中 | 高 | ASTS / Lynk 等非 SpaceX 玩家尤其敏感 |

替代方案包括：地面小基站和固定无线接入、农村补贴网络、Wi-Fi calling、Apple/Globalstar 式专用 SOS、Iridium 窄带终端、HAPS 高空平台、蜂窝网络漫游增强。D2D 的优势是“普通手机 + 广域覆盖”，弱点是容量和成本。

## 10. 芒格视角：这个行业最可能怎么让投资者亏钱

1. **把技术演示当商业验证。** 发一条短信、打一次电话、跑一次视频 demo，不等于可规模化盈利。
2. **把覆盖面积当收入。** 卫星覆盖的是地理面积，付费的是人和企业。偏远覆盖的付费密度天然低。
3. **低估入口方议价权。** 运营商、Apple、Android OEM 和芯片厂控制用户体验与账单。
4. **忽略资本开支和卫星折旧。** LEO 卫星寿命有限，补星是持续资本开支，不是一次性护城河。
5. **低估 SpaceX 的战略选择权。** 如果 SpaceX 愿意牺牲 D2D 短期利润换生态控制，行业价格锚会很低。

## 12. 对 ASTS 的结论

**评分：★★★☆☆（3/5，观察名单 / 高风险期权）**

ASTS 是 D2D/NTN 里最有“非线性收益”特征的上市标的之一，因为它押注的是普通手机宽带连接，而不是仅仅 SOS 或窄带消息。若星座部署、MNO 商业合作和单位经济性同时成立，ASTS 有机会成为全球运营商的卫星蜂窝批发层。

但从芒格视角看，ASTS 目前还不是“证明过的好生意”，而是“技术和合约正在逼近商业验证的期权”。真正需要跟踪的不是公司愿景，而是：

| 关键验证点 | 为什么重要 |
|---|---|
| 可持续商用收入，而不是一次性预付款或战略投资 | 验证 MNO 真实付费意愿 |
| 每颗卫星实际容量、覆盖时长、可用率 | 决定单位经济性 |
| 后续发射节奏和融资成本 | 决定能否跨过星座规模临界点 |
| 与 AT&T / Verizon / Vodafone 等 MNO 的零售套餐落地 | 决定从 demo 到收入的距离 |
| SpaceX D2D 定价和服务质量 | 决定 ASTS 的竞争价格锚 |

## 13. 3-5 条引用要点

1. 3GPP Release 17 已纳入 NTN，是卫星与蜂窝标准融合的关键起点；Release 18/19 继续增强 NTN 能力。
2. FCC 2024 年建立 SCS 框架，确认卫星可在合规条件下使用地面移动频谱提供补充覆盖，但干扰保护和逐国授权仍是硬约束。
3. Apple / Globalstar 已证明“手机卫星应急服务”有真实用户价值，但也证明终端平台可能拿走用户入口。
4. SpaceX Starlink Direct to Cell 是 ASTS 最大竞争变量，因为它同时拥有低成本发射、既有星座、资本和运营商合作复制能力。
5. ASTS 的核心差异在“普通手机宽带蜂窝直连”，但这条路线的商业验证仍早，必须跟踪收入、容量、发射节奏和 MNO 套餐落地。
